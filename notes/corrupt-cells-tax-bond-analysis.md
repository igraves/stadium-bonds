repository's initial commit, so there is no clean copy in version control.

Indentation survived, so a reconstruction is mechanically possible, but two

1. The cells' one multi-line `print(f"""...""")` block lost the newlines inside
   the string as well as between statements, so the formatting can only be

   prints `STAR FINANCING MODEL WITH ALL REVENUE STREAMS` — the saved outputs

   corrupted. The `data/tif_*.csv` files they wrote are therefore not a reliable
   check on a reconstruction either.

[`../star_financing_model.ipynb`](../star_financing_model.ipynb). Nothing outside
